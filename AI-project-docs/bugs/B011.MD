# B011: A failed plan load shows an empty board with no error

- **Found**: 2026-11-26, T001 review (step 3)
- **Severity**: Medium (the user sees an empty day and thinks the plan is gone; no message, no retry. No data loss: saves are per task)
- **Where**: `ui-personal-routine-manager/src/features/daily/hooks/useDailyPlan.ts` (`refresh`), `features/daily/pages/DailyRoutinePage.tsx`

## What happens
When `fetchDailyRoutine` fails, `refresh` logs to the console, sets `loadError` and an empty routine (`{ date, tasks: [] }`). The page never reads `loadError`, so the Today board is just empty.

## Reproduction
Stop the backend (or make `GET` daily routine return 500), open Today: empty board, no error.

## Expected
An error message with a retry action instead of the empty board.
