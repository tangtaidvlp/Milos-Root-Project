# B015: Push mode — making a task shorter doesn't bring the tasks below up

- **Found**: 2026-11-27, F017 manual testing (Today board)
- **Severity**: Medium (workaround: move the tasks below by hand)
- **Where**: timeline board, Push mode, resize handle (`ui-personal-routine-manager/src/features/board/utils/dragPreview.ts`)

## What happens

In Push mode, dragging a task's bottom edge up (shorter) leaves the tasks below where they were.

## Reproduction

Push mode on; Work 09:00–11:00, Lunch 12:00–13:00; drag Work's bottom edge up 1 hour → Lunch stays at 12:00.

## Expected

Like a move, the tasks below follow: Lunch moves up to 11:00–12:00 (gap kept).

## Notes

Fixed in `specs/.done.B015-fix-push-shrink-pull-up/bugfix.md`.
