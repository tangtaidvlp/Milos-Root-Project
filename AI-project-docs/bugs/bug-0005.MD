# bug-0005: Buddy's update/delete tools fail without an open Hibernate session

- **Found**: 2026-11-23, F008 (T040)
- **Severity**: Medium (latent: breaks Buddy's edits on any profile with `spring.jpa.open-in-view: false`, such as `prod`)
- **Where**: `service/aitools/DailyRoutineAiTools.updateDailyTasks` / `deleteDailyTasks`, `service/aitools/DefaultRoutineAiTools.updateDefaultRoutineTasks` / `deleteDefaultRoutineTasks`

## What happens
These tool methods load the routine and then read its lazy `tasks` list with no transaction. Without a session spanning the request, they reply "Failed to update daily tasks: Cannot lazily initialize collection of role '...DailyRoutine.tasks'".

## Reproduction
Call `dailyTools.updateDailyTasks(...)` directly (outside a transaction) in a component test: the reply starts with "Failed to update". F008's tests wrap these calls in a `TransactionTemplate` and point to this bug.

## Expected
The tools work regardless of open-in-view: they load the tasks inside a transaction (or through a fetch query) while keeping their "reply with a message, don't throw" behaviour.
