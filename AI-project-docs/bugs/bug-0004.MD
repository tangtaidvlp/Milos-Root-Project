# bug-0004: Logout doesn't revoke the stored refresh token

- **Found**: 2026-11-23, F008 (also in constitution 1.0.0 known gaps, IV)
- **Severity**: Medium (security: a copied refresh cookie keeps working after the user logs out)
- **Where**: `api/AuthenticationController.logout` (the `authenticationService.logout(userId)` call is commented out)

## What happens
Logout only clears the cookie in the browser. The refresh token row stays valid until it expires.

## Reproduction
Component test: log in (keep the cookie value), `POST /api/v1/auth/logout`, then `POST /api/v1/auth/refresh` with the old cookie → 200.

## Expected
401 after logout: the token is revoked (or deleted) server side.
