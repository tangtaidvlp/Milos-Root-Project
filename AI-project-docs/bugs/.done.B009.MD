# B009: AI chats return 500 instead of 503 when Buddy fails

- **Found**: 2026-11-24, E001 (F013 iteration review)
- **Severity**: Medium. The user sees "Unexpected error" instead of a friendly "Buddy is unavailable" message; the constitution requires 503.
- **Where**: `ms-personal-routine-manager` `api/AIController.java`: `POST /api/ai/chat/default-routine/{userId}`, `/daily-routine/{userId}`, `/daily-reflection/{userId}`

## What happens

When the AI call throws (provider down, bad key, timeout), these 3 chats don't catch it. `GlobalExceptionHandler` turns it into 500 "Unexpected error" and logs it as an unhandled error. The Personal Target chat, reflection feedback and goal review already return 503.

## Reproduction

Make `aiChatService.defaultRoutineChat` / `dailyRoutineChat` or `reflectionAi.chat` throw, then send a chat message: you get 500.

## Expected

503 with the `ApiError` body and a friendly message ("Buddy is unavailable right now…"), nothing stored for the failed exchange (constitution Principle V).

## Notes

Nothing is stored today either, because the exchange is saved only after the reply.
