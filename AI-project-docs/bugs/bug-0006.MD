# bug-0006: The `prod` profile can't return routines (500)

- **Found**: 2026-11-23, F008 (T047)
- **Severity**: High if `prod` is used (every routine read fails); latent today (the EC2 backend runs the `test` profile)
- **Where**: endpoints returning JPA entities with lazy collections: `DefaultRoutineController`, `DailyRoutineController`; `application-prod.yml` sets `spring.jpa.open-in-view: false`

## What happens
With open-in-view off, the transaction is closed when Jackson writes the response. Serialising `DefaultRoutine.tasks` / `DailyRoutine.tasks` throws "Could not write JSON: Cannot lazily initialize collection", so the response is a 500.

## Reproduction
Set `spring.jpa.open-in-view: false` in `src/test/resources/application-test.yml` and run `./gradlew test`: 24 component tests fail with 500 on routine endpoints.

## Expected
Routine endpoints work with open-in-view off: return DTOs built inside the transaction (constitution I: "JPA entities MUST NOT be serialised directly in new code").
