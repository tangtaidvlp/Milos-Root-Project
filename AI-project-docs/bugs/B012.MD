# B012: A failed task delete gives no feedback

- **Found**: 2026-11-26, T001 review (step 3)
- **Severity**: Medium (the user clicks delete and nothing happens; the error is only in the console)
- **Where**: `ui-personal-routine-manager/src/features/daily/hooks/useDailyPlan.ts` (`deleteTask`), used by the board and the task modal in `DailyRoutinePage.tsx`

## What happens
`deleteTask` catches the error from `deleteDailyTasks` and only calls `console.error`. The task stays on the board with no message.

## Reproduction
Make `DELETE` daily tasks fail (stop the backend or return 500), delete a task from the board or the task modal: nothing visible happens.

## Expected
The user sees that the delete failed (for example an inline error or toast) and can try again.
