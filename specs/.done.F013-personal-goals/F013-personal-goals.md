# F013 – Personal goals

**Type**: Feature
**Epic**: E001

## Summary

A "Personal Target" page where users set up to 3 goals, each with what they want Buddy to help with. Buddy uses the goals in every chat and can propose goal changes that the user confirms.

## Problem / Motivation

Buddy doesn't know what the user is working towards, so its suggestions are generic. It can't guide or correct the user against their own goals.

## Users

Signed-in users.

## What the user should be able to do

- Add, edit and delete up to 3 goals on the Personal Target page.
- Get Buddy suggestions that follow their goals and the help they asked for.
- Accept or dismiss a goal change that Buddy proposes in chat.

## Rules & Constraints

- At most 3 goals per user.
- Buddy never saves or deletes a goal without the user's confirmation.

## Out of Scope

- Buddy tone (F014) and context-aware tone (F015).
